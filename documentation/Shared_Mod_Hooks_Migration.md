# Shared hook migration

No mod changed in this branch. Paths below are relative to each named mod worktree. Delete only the named patch class, leaving other classes in a shared file. Remove its Harmony registration too. The replacements and examples are in [Shared mod hooks](Shared_Mod_Hooks_Guide.md).

| Mod | Patch class and file to remove after migration | Replacement and retained work |
| --- | --- | --- |
| Lifespan | `ChildCapabilityPatches.WalkSpeedPatch`, `Lifespan/ChildCare/ChildCapabilityPatches.cs`; `ChildCapabilityPatches.ExpeditionOnShowPatch` in the same file | Apply a per-character `WalkSpeed` factor and minimum through `Attributes.Apply`, then subscribe to `ShelteredEvents.ExpeditionPanelShown`. Keep job eligibility patches. Replace m_mesh reflection in `Lifespan/ChildTransitionManager.cs`, `BabyCribVisualManager.cs`, and `LifespanPlugin.cs` with `ShelteredCharacters.TryGetBody`; use `TrySetBody` for age body transitions. Do not remove a patch until its subscriber/contribution is active. Do not retain the speed or density patch alongside its replacement contribution, because both would apply. Native body access still lets a mod overwrite another mod's appearance; mods must coordinate their appearance policy. This change removes private-field reflection, not conflicting artistic choices.
