# Sheltered Mod Manager — Nexus Application Registration Review

## Application identity

- Name: Sheltered Mod Manager
- Review version: 2.0.0
- Nexus game domain: `sheltered`
- Nexus manager page: `https://www.nexusmods.com/sheltered/mods/1`
- Source: `https://github.com/coolnether123/shelteredmodmanager`
- License: MIT

Sheltered Mod Manager is a Windows desktop manager and modding framework for Sheltered. Its Nexus integration browses Sheltered mods, checks installed versions, resolves user-authorized download mirrors, safely installs compatible ZIP packages, and opens manual Nexus pages when a file cannot be installed directly. Legacy file-list `manager` metadata is not treated as authoritative because current Sheltered files report it inconsistently; the download-link endpoint or website-issued authorization makes the final access decision.

## Reviewer setup

1. Place the included `SMM` folder inside a Sheltered installation directory, or launch `SMM\Manager.exe` directly to review metadata browsing without a game install.
2. Open Settings > Nexus and enable Nexus features.
3. Paste a personal Nexus API key. The key is validated through `/v1/users/validate` and stored locally with Windows DPAPI CurrentUser protection. No key is included in this archive or sent anywhere except Nexus Mods.
4. Open the Nexus tab and verify Discover, the Manager update check, and an installed-mod update check.
5. Select an installable Sheltered mod and choose Install.

## Download behavior

- Premium: the Manager requests mirrors through the official v1 download-link endpoint.
- Non-premium/supporter: Nexus requires a short-lived `key` and `expires` authorization generated by the website's Mod Manager Download action. SMM temporarily registers for the next `nxm://` link, restores the user's previous handler immediately after capture or automatically after 15 minutes, validates the link, and then requests the mirror through the same official endpoint.
- Resolved mirror URLs and nxm authorization values are never cached. Cross-process nxm relay files are DPAPI-encrypted and deleted after consumption.
- SMM currently installs ZIP packages only and validates the package structure and target before replacing files.
- Rollback backups stay on the configured mods volume, allowing safe updates when the Manager executable and the managed Sheltered installation are on different drives.

## API selection

- v2 GraphQL is used for low-request metadata browsing and batched update checks.
- v1 remains in use for key validation, file listing fallback, and download-link resolution because these capabilities are not available in the v3 OpenAPI.
- v3 stable upload-session endpoints and current experimental mod-file endpoints exist in dormant author tooling. API publishing is forcibly disabled in public 2.0 builds pending separate Nexus approval.

Every Nexus API request includes:

- `Application-Name: Sheltered Mod Manager`
- `Application-Version: 2.0.0`
- `User-Agent: ShelteredModManager/2.0.0`

## Suggested review cases

- Valid, invalid, and revoked personal API keys.
- Premium direct download.
- Regular-member website-authorized Mod Manager Download.
- A file that disallows manager download.
- Deleted/hidden file, offline request, timeout, and HTTP 429 response.
- ZIP package with an invalid SMM layout and an attempted duplicate mod ID.
