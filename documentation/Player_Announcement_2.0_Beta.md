# Player Announcement: SMM 2.0 Beta

Sheltered Mod Manager 2.0 Beta is available for testing.

This is a beta, not a stable release. SMM 2.0 uses a new split mod system, so mods made for SMM 1.2.2 or the old 1.3 beta line may not work until updated.

Before switching:

- Back up saves.
- Use 2.0 versions of mods when available.
- Read mod compatibility warnings in the manager.
- Read save verification warnings before loading old saves.

The goal of this beta is to verify installation, mod updates, compatibility warnings, Nexus downloads, and public 2.0 mod packages before calling the release stable.
