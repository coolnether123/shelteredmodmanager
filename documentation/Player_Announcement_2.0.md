# Player Announcement: SMM 2.0

Sheltered Mod Manager 2.0 is available.

SMM 2.0 uses a new split mod system, so mods made for SMM 1.2.2 or the old 1.3 beta line may not work until updated.

Before switching:

- Back up saves.
- Use 2.0 versions of mods when available.
- Read mod compatibility warnings in the manager.
- Read save verification warnings before loading old saves.

The goal of this release is to provide the stable 2.0 API split while keeping save verification and compatibility warnings visible during upgrades.
